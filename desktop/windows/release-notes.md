Riffine's first native Windows alpha uses a WinUI interface with the shared
practice and audio engines. Requires Windows 10 version 2004 or newer, or
Windows 11, on x64.

Open a music folder or WAV/FLAC/MP3 song, select a phrase on its waveform, adjust
speed and pitch, preview it, and save a portable practice project. Audio stays
on your device. Keep the original song available when reopening a project.

Download the `windows-x64-setup.exe` asset to install. `SHA256SUMS.txt` contains
its SHA-256 checksum. This alpha is unsigned.

Preview plays the selected range once; change settings between previews.
Continuous looping, pause/seek, live changes, volume/mute and full feature parity
with the web app remain in development. Browser M4A/Opus support is not yet
available in this native build. Physical-device and accessibility acceptance
remain outstanding.
